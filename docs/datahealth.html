判定規則（寫死喺 freshness.py，唔可以事後改）
FRESH = 檔案存在，而且日齡 ≤ 該源嘅 max_age
STALE = 檔案存在但超過 max_age（通常代表 job 冇跑）
MISSING = 完全搵唔到檔案

為什麼用日曆日而唔係交易日？ 交易日需要市假日曆，容易出錯；日曆日 + 寬鬆門檻更安全。週末會出現 STALE（週五數據在週日 age=2），所以 max_age 已預留。

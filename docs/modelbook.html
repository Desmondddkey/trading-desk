行為對照 理論 vs 你嘅實盤

① 「耐心與等待」 理論：冇 setup 就現金。
　你嘅實盤：每日平均 16.2 單；做 20+ 單 嘅日子每單 −$23（n=557）。
　→ 做得越多，每單越差。

② 「恐慌與貪婪」 理論：極端情緒係轉折點。
　你嘅實盤：睇漲單（多數喺情緒高位入）每單 −$18（n=1,103，勝率 30%）。
　→ 情緒高位做多 = 最差嘅組合。

③ 「止蝕與紀律」 理論：止蝕係入場費。
　你嘅實盤：30 分鐘內平倉 每單 −$33（n=601）；持倉 1–5 日 每單 +$45（n=153，勝率 54%）。
　→ 持倉越長越好 —— 同「止蝕要快」唔矛盾，係「止蝕快、贏單慢」。

④ 「做空邏輯」 理論：跌市做空。
　你嘅實盤：看跌每單 +$25；看漲 −$18。
　→ GMI 1/6 RED 時，做空係唯一正期望。

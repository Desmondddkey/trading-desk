Think in R 原則 來源：AMD 交易檢討

① 用 R 思考，唔用錢
　「賺 $500」冇意義。「賺 4.5R」才有意義 —— 因為 R 已經包含風險。

② 4-5R 就平倉
　原話：「我最近大部分交易，總係上到 4-5R 就即刻平倉」
　唔係等 10R、唔係等 20R。4-5R 就夠。

③ 分批：4R 賣第一批 → 止蝕移保本
　「賣出首批修剪，止蝕移到保本，手上就有一單贏交易」

④ 唔在乎離場後仲升
　「呢隻股喺我離場後走得更高，我完全唔在乎」
　因為目標唔係食盡，係穩定執行。

⑤ 每次檢討都問：呢單幾多 R？
　唔係「賺定蝕」，係「幾多 R」。
R 定義：1R = 你平均輸單絕對值（$78）。實盤記錄冇逐單止蝕價，所以用呢個標準近似值。
限制：如果你某段時間止蝕特別闊／窄，嗰段嘅 R 會失真。
數據：2154 張成交單 → 1316 個 round-trip，同 Edge Improving 頁同一來源。
所有資料唯讀、研究用途，非買入指令。入場要另行符合 ORH + RVOL 規則；倉位由 daily_plan.stop_plan() 決定。

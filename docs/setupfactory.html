🏭 Setup Factory —— 技巧資料庫

一句總結：先找已經證明強勢嘅領導股，等待它回到可定義風險嘅支撐，再用價格觸發驗證反轉；喺擴張中兌現部分，保留核心讓趨勢決定後續。
來源：1ChartMaster 策略圖解（4,446 條歸檔帖文，2025-09-04 → 2026-10-06，9 個精選案例）。本站與作者無隸屬關係。

① 相對強勢→② 支撐→③ 轉折→④ 管理
01📈 RS 領導股
先找已經證明強勢嘅股，唔係找便宜股。RS 係篩選方向，唔係入場信號。
睇咩
· RS 線有冇【先於】股價創新高（divergence）
· 板塊有冇帶動作用
· 有冇財報或產業催化
🛑 失效：RS 強但價格冇支撐 → 唔可以追高。RS 高 ≠ 可以買。
🖥 我哋系統：✅ rs_before_price.py（RS 先創新高但價未跟上）｜layer2a_rs（RS Rating 0–99）
02↩️ 強勢後的回撤
買「強勢之後嘅弱勢」—— 股票先有動能，然後回調到缺口／舊 pivot／趨勢線／均線。作者後期特別強調：許多最佳交易係喺突破【之前】嘅回調中建立。
睇咩
· 回調位置係咪「可解釋嘅支撐」（缺口、舊 pivot、趨勢線、均線）
· 回調幅度有冇縮（一級比一級細）
· 成交量有冇縮（供應減少）
🛑 失效：回調穿咗結構低點 → 唔係回調，係轉勢。
🖥 我哋系統：✅ layer2_focus_stalk（pullback 條件）｜HPAT（H 型態，n=790 EV +0.83R t=+3.55）
03📐 結構與均線
8 週 EMA 係重要週線參考；日線常出現 8 日／21 日 EMA 或其他結構支撐。Inside day、旗形、VCP、橫向整理與量縮用嚟觀察供應減少。
睇咩
· 8 週 EMA（週線）有冇上升
· 8 日 / 21 日 EMA 有冇托住
· Inside day / VCP / 旗形 —— 波幅逐級收窄
· 缺口與舊阻力轉支撐（S/R flip）
🛑 失效：均線向下 + 波幅放大 = 唔係收縮，係派發。
🖥 我哋系統：✅ 8/21 EMA 喺 charts 圖｜VCP 部分（setup_alerts 6-setup）⚠ 8 週 EMA 尚未系統化
04⏱ 30 分鐘 pivot（觸發）
喺強勢股下跌或回落至關鍵支撐後，等第一根乾淨嘅【30 分鐘陽線】收完；下一根越過佢高點才觸發，止損放喺該陽線低點下方。用支撐位置 + 小週期確認。
睇咩
· 支撐已經到（位置）
· 出現一根乾淨 30 分鐘陽線（時機）
· 下一根越過陽線高點 → 觸發
· 止損 = 陽線低點下方
🛑 失效：跌穿陽線低點 → 呢次反轉失效，即刻走。
🖥 我哋系統：⚠ 未實作（我哋用日線 pivot，唔係 30 分鐘）｜ORH 警報部分接近，但係開盤區間唔係反轉 pivot
05🛑 失效點（先想錯）
結構低點或 pivot K 線低點係初始失效參考。突破觸發後反向跌穿失效點，及時退出；新信號成立時可以重新評估 —— 唔把一次止損當永久禁買。
睇咩
· 初始止損喺邊（結構低點 / pivot K 線低點）
· 距離入場幾多 % / 幾多 ATR
· 跌穿之後有冇新觸發（可以重入，但要有新信號）
🛑 失效：跌穿止損仍然抱住 = 呢個唔係止損，係希望。
🖥 我哋系統：✅ jeffsun_stop.py（Day 0–2 LoD）｜LOD ≤ 0.60 ATR 入場閘
06✂️ 冲高減倉
喺垂直擴張或供應阻力附近賣出部分，回收風險並降低隔夜暴露；有利潤墊嘅剩餘倉位繼續跟隨趨勢。作者常舉 1/3，實際案例有 1/2 同 3/4。
睇咩
· 有冇垂直擴張（幾日內急升）
· 接近阻力／供應區
· 減幾多 —— 1/3 常態，唔夠好嘅入場可以更積極
🛑 失效：減倉比例唔係固定參數。把 3/4 宣傳成全策略固定值 = 錯。
🖥 我哋系統：✅ SOUL §4 分批止賺：2R 減 33% → ATRX>8 再減 33% → 拖 10EMA
07🌧 行情難做時降低參與
大盤均線向下、廣度弱或信號缺乏持續性時，減小 swing 暴露、喺強勢中更積極減倉、減少隔夜風險。連續失敗時停止當日繼續嘗試，保留資金等更清楚嘅機會。
睇咩
· 大盤均線向上定向下
· 廣度（% 股票喺 50MA 上）
· 連續失敗幾多次
🛑 失效：連續失敗仍然加碼 = 報復交易。
🖥 我哋系統：✅ market_regime.py（Weinstein 四階段 + MMFI）｜discipline_gate.py（連蝕 3 日停）｜portfolio_brake.py（連蝕 3 日停手、賺 5 萬鎖半倉）

🧪 Strategy Lab —— 逐步睇一個 setup 點發生

揀一步睇該階段要睇咩。對應原文「選擇一種形態，逐步查看環境、等待、觸發和失效」。
1 / 環境
先從 RS 候選清單出發，確認佢此前有強勢、大週期上存在可解釋嘅支撐。
圖上重點：下跌段 + 支撐位置
2 / 等待
等回落到支撐，然後觀察有冇收縮、量縮、波幅一級比一級細。未觸發前唔做嘢。
圖上重點：SQUAT / VCP 區
3 / 觸發
出現一根乾淨 30 分鐘陽線並收完；下一根越過該陽線高點 → 買入觸發。
圖上重點：陽線 + 突破線
4 / 失效
初始止損放喺同一根陽線低點下方。跌穿 = 呢次反轉失效，即刻走，唔等收市。
圖上重點：止損紅線
所有價格為示意，唔係歷史回測。觸發點同失效位置用嚟說明思路，唔代表作者固定交易參數。

⚠ 邊界 —— 唔可以當成完整系統

· 「乾淨陽線」缺少可編程嘅實體、影線同最小波幅定義
· 下方緩衝、滑點、訂單類型同頭寸公式未統一
· 唔可以把每根低位陽線都當成呢個 setup
· 減倉比例（1/3、1/2、3/4）係情境反應，唔係固定參數
· RS 評分同藍點算法未完整公開
· 觀察帖 ≠ 已成交交易；後續市價 ≠ 賣出價

📖 術語速查

術語解釋
RS / RS Rating / 藍點相對市場或基準嘅強弱；藍點常用嚟標示相對強勢新高。RS 同 RSI 唔同，評分同藍點算法未完整公開。
Pivot可交易嘅價格關口或反轉觸發。日線 pivot、開盤區間 pivot 同下跌後嘅 30 分鐘反轉 pivot 要按上下文區分。
DTL / DTR下降趨勢線 / 下降趨勢阻力。作者觀察突破、回測與阻力轉支撐。
S/R flip原先阻力被突破後，回測時轉為支撐；仍須觀察能否守住。
8-week EMA週線 8 週指數均線，係作者動能股回調嘅重要參考。
Squat強勢股回退或橫行喺均線／結構支撐附近，形成收緊嘅待觸發狀態；唔係所有跌勢都叫 squat。
Inside day / week當日／當週高低點處於前一週期高低點之內，用嚟觀察波動收縮同較清楚嘅觸發、失效區間。
VCP / HTF波動收縮形態 / 高緊旗形。作者觀察強動能之後嘅淺回調、收緊與量縮，但兩者唔可以隨意互換。
HVE / PEG歷史最高成交量 / 財報後跳空。HVE 係重要標籤，仍需結合事件發生喺底部、整理或長上漲後嘅唔同位置。
ORB開盤區間突破；本檔案多頭例子用開盤第一根 30 分鐘 K 線高點作觸發。
Chop / Trim / Core賣出部分、減倉與保留嘅核心倉位；用強勢中嘅兌現支付風險，再讓剩餘繼續跟隨。
R / Free tradeR 係初始計劃風險嘅計量；free trade 係已兌現利潤覆蓋剩餘計劃虧損嘅管理說法，結果仍取決於實際執行。
所有資料唯讀、研究用途，非買入指令。入場要另行符合 ORH + RVOL 規則；倉位由 daily_plan.stop_plan() 決定。
